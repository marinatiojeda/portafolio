Billetera Digital Web

Proyecto funcional

Aplicación web que simula el funcionamiento de una billetera digital. Permite iniciar sesión, consultar el saldo, depositar fondos, enviar dinero y revisar el historial de movimientos.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap
  • jQuery
  • LocalStorage

Funcionalidades

  • Inicio de sesión simulado.
  • Consulta y actualización del saldo.
  • Registro de depósitos.
  • Envío de dinero a contactos.
  • Historial dinámico de movimientos.
  • Filtros por tipo de transacción.
  • Diseño adaptable a celulares.

Base de Datos de Billetera Digital

Proyecto finalizado

Sistema de base de datos relacional desarrollado para administrar usuarios, monedas y transacciones de una billetera digital.

Tecnologías utilizadas

  • MySQL
  • SQL
  • MySQL Workbench

Aprendizajes aplicados

  • Creación de tablas y relaciones.
  • Claves primarias y claves foráneas.
  • Consultas y manipulación de datos.
  • Uso de INSERT, UPDATE y DELETE.
  • Transacciones con COMMIT y ROLLBACK.
  • Aplicación de integridad referencial.
