💳 Billetera Digital Web

Proyecto funcional

Este proyecto consiste en una aplicación web que simula el funcionamiento de una billetera digital.

La aplicación permite que una persona inicie sesión, consulte su saldo, realice depósitos, envíe dinero a contactos y revise el historial de sus movimientos.

Fue desarrollada como parte de mi formación en Desarrollo de Software, aplicando conocimientos de estructura HTML, diseño con CSS, programación con JavaScript y almacenamiento de información en el navegador.

Objetivo del proyecto

Desarrollar una aplicación web interactiva que permita representar las operaciones principales de una billetera digital, mediante una interfaz sencilla, clara y adaptable a distintos tamaños de pantalla.

Tecnologías utilizadas

  • HTML5 para la estructura de las páginas.
  • CSS3 para el diseño visual y la adaptación a celulares.
  • JavaScript para la lógica y las funciones de la aplicación.
  • Bootstrap para algunos componentes y estilos adaptables.
  • jQuery para apoyar la interacción con elementos de la página.
  • LocalStorage y SessionStorage para guardar información temporalmente en el navegador.
  • Visual Studio Code como entorno de desarrollo.

Páginas de la aplicación

  • Página de inicio.
  • Inicio de sesión.
  • Menú principal de operaciones.
  • Página para depositar dinero.
  • Página para enviar dinero.
  • Página con el historial de transacciones.

Funcionalidades implementadas

  • Validación de las credenciales de acceso.
  • Creación de una sesión para la persona que inicia sesión.
  • Visualización del saldo disponible.
  • Registro de depósitos.
  • Actualización automática del saldo después de un depósito.
  • Envío de dinero a contactos.
  • Verificación del saldo antes de realizar una transferencia.
  • Descuento automático del monto transferido.
  • Registro de movimientos y transacciones.
  • Filtro del historial según el tipo de operación.
  • Cierre de sesión.
  • Diseño adaptable para computador, tablet y celular.

Organización del proyecto

El proyecto fue organizado en diferentes archivos para separar la estructura, el diseño y la programación.

  • Los archivos HTML contienen las diferentes páginas de la aplicación.
  • El archivo CSS contiene los estilos y el diseño adaptable.
  • El archivo JavaScript contiene las validaciones, el manejo del saldo y el registro de las operaciones.

Lo que aprendí

Con este proyecto aprendí a conectar diferentes páginas HTML, crear formularios, validar datos ingresados por el usuario y modificar información mediante JavaScript.

También aprendí a utilizar el almacenamiento del navegador para conservar el saldo y las transacciones, además de organizar el código en funciones reutilizables.

Otro aprendizaje importante fue mejorar la experiencia del usuario mediante mensajes de validación, navegación clara y un diseño que se adapta a diferentes dispositivos.

Relación con la base de datos

Esta aplicación web se relaciona con otro proyecto que realicé en MySQL para administrar usuarios, monedas y transacciones de una billetera digital.

Actualmente, esta versión funciona con datos almacenados en el navegador. Como mejora futura, podría conectarse a una base de datos y a un servidor para almacenar la información de manera permanente.

Próximas mejoras

  • Conectar la aplicación con una base de datos MySQL.
  • Incorporar un servidor y una API.
  • Crear usuarios reales y contraseñas protegidas.
  • Agregar nuevos contactos desde la aplicación.
  • Incorporar validaciones adicionales.
  • Publicar una demostración en línea.
